# Tipografías (copia incluida a propósito)

- **Montserrat** (texto) y **Roboto** (títulos), versión variable, subconjunto latino (cubre el español).
- Licencia: SIL Open Font License 1.1, que permite redistribuirlas con el software.
- Origen: Google Fonts (`fonts.gstatic.com`), versiones Montserrat v31 y Roboto v51.
- Si un navegador no las encontrara, usa una fuente del sistema (ver `font-family` en `templates/base.html`).
